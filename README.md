# Bhavani Transport — AI-Powered Logistics Scheduling Platform

Static front-end demo website for the final-year project.

## Files
- index.html : page structure and content
- style.css  : styling (light and dark mode)
- script.js  : booking-suggestion demo and admin dashboard demo (simple rules, sample data)

## Run
Open index.html in any browser. No installation needed.

## Note
The demo does not call the OpenAI API. The full project uses Next.js, Node.js/Express, Prisma, Clerk, Cloudinary and the OpenAI API.
